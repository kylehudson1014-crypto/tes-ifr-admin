# Patriot Pilot Academy — School Admin portal (v16)
Static build of the TES IFR app in **admin** mode: Scheduling timeline, accounts & packages, fleet & squawks,
owner report, members & roles, logbook review queue, data migration. Staff sign in with their school account;
**Explore Demo Mode** works with no sign-in. Source: tes-ifr-poh-preview (`tools/build_split.py`). Data model: DATA-MODEL-v16.md.
Live: https://kylehudson1014-crypto.github.io/tes-ifr-admin/
